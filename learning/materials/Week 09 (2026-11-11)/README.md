# Week 09: 기업의 프로모션 규칙을 이용한 효과 측정

Busse 등은 자동차 지원금 시작일과 비교 차종의 가격 변화를 이용해 소비자가 얻는 혜택을 계산합니다. Hartmann 등은 고객 점수와 지역 경계에서 마케팅 대우가 달라지는 규칙을 분석합니다. 공통으로 기업의 배정기준을 이용하지만 고객이 구매 시점이나 점수를 조정할 수 있는지가 중요한 차이입니다.

심층요약은 연구의 질문에서 출발해 비교방법, 수식과 결과 해석을 설명합니다. QnA는 PDF마다 개념 독해 퀴즈 10문항과 각 문항 바로 아래의 예상 답안으로 구성했습니다. 실제 연구상황을 제시하고 목적, 비교 설계, 측정과 결과의 의미를 설명하도록 묻습니다. 수식의 상세 전개는 심층요약에서 확인할 수 있습니다.
