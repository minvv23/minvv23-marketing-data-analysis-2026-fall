# Week 06 자료별 학습 안내

[전체 주차 목록](../README.md)

이 주에는 IV의 가정을 실제 연구의 판단과 연결한다. AIR는 약물 복용과 징병 사례에서 배정과 실제 행동을 구분하고 가정 위반의 영향을 계산한다. MHE 4.5-4.6은 여러 도구와 처치 강도를 사용하는 경우의 평균효과, 두 단계 회귀의 계산, 약한 도구를 설명한다.

자동차 논문은 인터넷 소개서비스 이용자가 원래 협상을 잘하던 사람인지, 오히려 협상에 어려움을 겪던 사람인지를 묻는다. 서비스의 작동 방식과 가격 측정부터 살펴본 뒤 도구의 논리와 결과를 평가한다. AIR의 가정 설명, 교재의 계산, 자동차 논문의 적용 순서로 공부하면 세 자료의 역할이 이어진다.

각 요약은 연구 배경부터 기호, 중간 계산, 결과 해석까지 설명한다. QnA에는 자료마다 개념적 독해 확인 퀴즈 10개와 각 질문 바로 아래의 구체적인 예상답안을 제공한다. 수식 유도와 산술 계산은 심층요약에서 다룬다. 판본과 원문 확인 범위는 문서 마지막의 출처 메모에서 확인할 수 있다.

판본 주의: AIR 파일은 1993년 NBER 작업논문이며, Cowboys 파일은 2001년 NBER 표지와 후속 수정 본문이 함께 있다. 표본 수와 수치 불일치, 발췌 끝의 누락 범위는 각 요약에 명시했다.
