# Week 07: 관측자료의 비교가능성과 의료정보 공개

Imbens의 글은 비슷한 특성의 처치자와 비처치자를 비교할 때 어떤 효과를 구할 수 있는지 설명합니다. Yoon의 연구는 환자의 연도별 구성을 매칭으로 조정한 뒤 의료 성적표 공개와 환자 배분의 관계를 분석합니다. 두 자료를 함께 읽으면 매칭이 해결하려는 문제가 연구마다 다를 수 있다는 점을 확인할 수 있습니다.
