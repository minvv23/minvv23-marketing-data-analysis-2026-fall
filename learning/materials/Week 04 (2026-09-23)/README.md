# Week 04 자료별 학습 안내

[전체 주차 목록](../README.md)

의료 성적표 논문은 정보 공개가 병원과 환자의 행동을 바꿀 때 어떤 사람을 분석대상에 포함해야 하는지 설명한다. 수술환자의 평균 사망률이 좋아져도 수술받지 못한 중증환자의 결과가 악화될 수 있다는 문제에서 출발한다.

MHE 4.1-4.2는 교육과 임금을 함께 결정하는 능력 차이를 어떻게 다룰지 묻는다. 출생분기와 징병 추첨의 제도적 배경에서 시작해 IV 비율, 두 단계 회귀, 표준오차가 필요한 이유를 설명한다. 두 자료는 각각 정책 노출의 비교와 실제 행동의 내생성을 다룬다.

| Is more information better (2003) | [PDF](<Is more information better (2003).pdf>) | [요약](<Is more information better (2003)_심층요약.md>) | [QnA](<Is more information better (2003)_QnA.md>) |
| MHE Ch4.1-4.2 IV and Causality, 2SLS Inference (2009) | [PDF](<MHE Ch4.1-4.2 IV and Causality, 2SLS Inference (2009).pdf>) | [요약](<MHE Ch4.1-4.2 IV and Causality, 2SLS Inference (2009)_심층요약.md>) | [QnA](<MHE Ch4.1-4.2 IV and Causality, 2SLS Inference (2009)_QnA.md>) |

각 요약은 연구 배경부터 기호, 중간 계산, 결과 해석까지 설명한다. QnA에는 자료마다 개념적 독해 확인 퀴즈 10개와 각 질문 바로 아래의 구체적인 예상답안을 제공한다. 수식 유도와 산술 계산은 심층요약에서 다룬다. 판본과 원문 확인 범위는 문서 마지막의 출처 메모에서 확인할 수 있다.
