노조원 임금이 높은 이유와 최저임금 인상 뒤 고용이 달라진 이유를 같은 사람, 같은 지역의 변화로 조사한다. MHE 5장에서 고정효과와 DID 계산을 먼저 익힌 뒤 Bertrand 논문에서 시간에 걸친 충격을 표준오차에 반영하는 이유를 읽으면 좋다. Goldfarb 논문은 이 비교 논리를 광고와 플랫폼의 실제 의사결정으로 연결한다.
