# 모바일·디자인 점검 (2026-09-22)

## 확인 범위

Chromium 브라우저에서 화면 폭 320·360·390·430px, 높이 844px로 확인했다. 실제 스마트폰 Safari/Chrome이나 네트워크 성능 측정은 수행하지 않았다.

각 폭에서 70개 문서를 순회하고, 각 QnA의 답안 10개를 모두 펼쳤다. 총 280개 답안이 있으며 페이지 전체의 가로 넘침은 없었다. 320px에서는 글자 크기를 키운 상태로 70개 문서를 추가 확인했다. 긴 수식·표는 내부 가로 스크롤을 허용한다.

자동 DOM 점검 외에 브라우저 클릭·입력 명령으로 메뉴 열기, 검색어 입력·삭제·교체, 검색 결과 열기, 요약→퀴즈 이동, 개별 답안 및 전체 답안 펼치기를 확인했다. 처음에는 검색창이 빈 값이 될 때 메뉴가 닫히는 문제가 있었고 수정 후 다시 확인했다. 탭 이동에 따른 펼친 답안 유지, 읽음 표시, 테마·글자 크기 변경도 확인했다.

## 디자인 가이드 반영

사용자가 지정한 `AI식-웹디자인-피하는법.md`의 시그널 32, 34 및 6-6, 6-8을 특히 참고했다.

- 정보가 없는 배경 radial-gradient 제거.
- 추상적인 첫 화면 문구를 과목명과 자료 사용 안내로 변경.
- 카드가 일률적으로 위로 움직이는 효과 제거. 현재 주차 표시는 배경과 굵기, `aria-current`로 구분.
- 기존 배경색·본문색·강조색과 글꼴을 유지. 문서의 '기존 시각 언어를 보존' 원칙을 우선했다. 따라서 Pretendard 권장 조항까지 모두 충족한다고 주장하지 않는다. 본문은 운영체제의 한글 고딕 글꼴, 수식은 로컬 KaTeX 글꼴을 사용한다.
- 주차 카드는 기능 소개용 3열 템플릿이 아니라 실제 13주 자료의 탐색 목록으로 유지. 모바일은 한 열로 변경.
- 모바일 버튼의 높이를 최소 44px로 확보하고 검색 입력 글자를 16px로 설정.
- 메뉴가 닫히면 접근성 트리와 키보드 탐색에서도 숨김. 바깥 영역 클릭 및 Escape로 닫기 지원.
- 긴 수식·표에 키보드 포커스 및 스크롤 영역 이름 제공.
- 모션 감소 설정 존중. 키보드 포커스 표시 유지.

체크리스트 개수로 합격을 판단하지 않았다. 스크린샷과 실제 읽기·탐색 동작을 함께 확인했다. 색 대비 전수 검사와 스크린리더 실기 검증은 별도로 수행하지 않았다.

## 파일

- `mobile-audit.js`: agent-browser eval로 실행하는 문서·사용 흐름 점검.
- `mobile-320.json` 등: 화면 폭별 결과.
- `mobile-home-320.png`, `mobile-quiz-320.png`, `mobile-math-320.png`: 좁은 화면의 홈·답안·수식 확인 화면.

추가로, 검색 결과에서 현재 URL과 같은 문서를 다시 누를 때 화면이 전환되지 않는 문제를 수정했다. 수정 후 320·360·390·430px 모두에서 실제 클릭으로 동일 문서 재진입을 확인했다. 긴 수식의 내부 `scrollLeft`가 실제로 이동하는 것도 확인했다.
