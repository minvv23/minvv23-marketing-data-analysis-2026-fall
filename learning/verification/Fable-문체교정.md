# 학습자료 문체 교정 기록

설치된 Claude Code 2.1.278을 `--model claude-fable-5-1[1m] --effort low`로 실행했다. 실행 결과의 실제 모델 식별자는 `claude-fable-5-1`이었다. 전역 모델 설정은 변경하지 않았다.

사용자의 `AI식-한국어-표현.md`를 기준으로 원본 Markdown 71개를 읽고 47개를 교정했다. 설명체와 존댓말이 한 문서에서 섞이는 부분, 불필요한 접속어, 번역투와 모호한 지시어를 다듬었다. 요약의 설명과 예시를 유지했다.

격리된 사본에서 교정한 뒤 원본과 비교하여 수식, 숫자, 링크, 제목 구조, QnA 문항 수가 그대로인지 확인했다. 개념을 흐릴 수 있는 ‘비처치자’는 ‘절대불참자’로 복원했고, probit과 2SLS의 역할을 설명하는 문장을 유지했다.

문체 교정 검사를 통과한 뒤 Week07 환자 재배분 요약의 기존 표기 오류 `$eta=-3$`를 `$\eta=-3$`로 수정했다. 앞서 정의한 로짓 선형지수와 표기를 맞춘 것으로 계산값은 바뀌지 않았다.

원본은 `literatures/`에 반영하고 `npm run sync:learning`으로 웹 자료에 동기화했다. 개별 파일 비교 기록과 교정 전 백업은 상위 프로젝트의 `documents/`에 보관한다.

검증 결과: 정적 빌드의 70개 페이지, 280개 문항, 1,768개 수식이 통과했다. 320px 모바일 브라우저에서 전체 페이지의 가로 넘침, 답안 펼치기, 검색, 주차 이동, 글자 크기와 테마 전환을 검사했으며 오류가 없었다. 기존 발표 페이지와 학습자료 하위 경로도 유지했다.
