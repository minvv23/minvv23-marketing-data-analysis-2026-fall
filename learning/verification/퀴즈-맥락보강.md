# 퀴즈의 질문 배경과 예상답안 보강

## 편집 범위

Week 01부터 Week 13까지 PDF별 QnA 28편, 총 280문항을 대상으로 했다. 각 문항은 짧은 제목, 연구 상황과 구체적인 질문, 예상답안 순서로 구성한다. 답안에서는 비교 대상과 논증을 설명하고, 관측 결과와 인과 해석, 원문 사례와 학습용 예를 구분한다.

설치된 Claude Code CLI에 `claude-fable-5-1[1m]`, `--effort low`를 지정해 PDF별로 작업했다. 실행 결과의 모델 이름은 `claude-fable-5-1`이다. 세 대화 TXT와 한국어 표현 지침을 설명 방식의 참고로 제공하고, 해당 심층요약과 PDF 추출 본문을 사실 확인 자료로 제공했다. Claude의 교정 후 통계적 해석과 표본 범위, 문체를 다시 검토했다.

Angrist, Imbens, Rubin의 IV 논문은 스캔본이라 본문 텍스트가 추출되지 않았다. 이 자료의 Claude 교정은 심층요약에 근거했으며, 후속 검토에서 PDF 이미지를 직접 열어 임상시험 사례, 사망률과 민감도 계산을 확인했다. 파일명과 달리 수록 판본은 1993년 NBER 작업논문이므로 문서에 판본을 명시했다.

## 웹 표시

질문의 상황 설명은 답안을 접어도 보인다. `예상답안` 표시부터 다음 문항 전까지를 답안 영역에 넣는다. 개별 답안과 전체 답안을 펼치거나 접을 수 있으며, 문서 사이를 이동해도 펼침 상태를 유지한다.

## 검증 방법

- 교정 전 백업과 비교해 기존 수식과 링크의 보존, 문항 번호와 답안 경계, 질문 배경과 답안의 누락 여부를 검사한다.
- 원본 Markdown을 웹 자료에 동기화한 뒤 빌드, KaTeX 검사, 내부 링크와 70개 문서 검사를 실행한다.
- `quiz-context-audit.js`는 전체 퀴즈의 질문 노출, 개별 및 전체 답안 펼침, 가로 넘침을 검사한다.
- `mobile-audit.js`는 전체 문서와 탐색, 검색, 읽음 표시, 글자 크기 및 테마 동작을 확인한다.

자동 검사는 문서 구조와 표시를 확인한다. 설명의 학술적 정확성은 자동 검사만으로 보장되지 않으므로 별도의 원문 대조와 검토를 수행했다.
