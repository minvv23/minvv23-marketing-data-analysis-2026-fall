# 원문 표와 해설 보강 (2026-09-23)

28개 PDF를 설치된 Claude Code의 `claude-opus-5-5`로 검토했다. 세 작업을 병렬로 실행했으며 reasoning effort는 medium이다. 회전된 표의 페이지 읽기가 실패한 1편은 원문을 이미지로 렌더링해 같은 모델로 다시 작업했다. 모든 최종 실행 결과의 모델 이름을 확인했다.

25개 심층요약에 원문 표와 해설을 추가했다. 기존 표가 있는 자료는 출처와 읽는 법을 보강했다. Harmony, Home Alarm Testing 2.0, Imbens (2004)는 추가할 원문 표가 없어 기존 요약을 보존했다.

- Markdown 표 70개 추가. 넓은 원문 표를 나눈 경우와 원문 계수로 계산한 예시도 포함하므로 원문 표 70개를 뜻하지 않는다.
- 원문 표 번호, PDF 파일 기준 페이지, 발췌 범위, 단위와 표준오차를 표시했다. 계산 예시는 원문과 구분했다.
- 추가한 표를 PDF 페이지 이미지와 대조하고, 비교집단·상호작용·로그 변환·유의성 해석을 검수했다. 원문 자체의 의심스러운 값은 임의로 고치지 않았다.
- 기존 본문은 모두 보존했다. QnA와 그 밖의 Markdown은 변경 전 백업과 바이트 단위로 일치한다.

## 검증
