# 그래프와 도식 추가 기록

2026-09-22. 13개 주차의 심층요약 17편에 SVG 그림 17개를 추가했다. 원본과 웹 사본은 같은 그림 파일을 사용한다. 본문과 수식을 그림으로 대체하지 않았으며, 교정 전 백업과 대조하여 그림 블록을 제외한 기존 Markdown이 모두 그대로임을 확인했다. QnA 문항도 변경하지 않았다.

고객 잔존율, 잠재결과, DID 반사실, IV 경로, 성적 공개와 환자 선별, LATE 유형, IV 가중평균, 매칭의 비교 범위, 로짓 확률, RD 경계, 광고 배정과 노출, 리베이트 전가율, 시차 도입 DID, 광고 파급효과, 리뷰 삭제 설계, 순위의 방향, 표시평점 반올림을 시각화했다.

논문과 교재의 수치를 재계산한 그림, 본문의 가상 예제, 수치 없는 개념도를 각 캡션에서 구분했다. Matplotlib으로 생성한 SVG는 한글 글자를 경로로 포함하므로 외부 글꼴이 필요 없다. 생성 코드와 그림별 설명은 저장소에 함께 보관했다.

## 검증

- 원본 구조 검사: PDF 28편, 심층요약 28편, QnA 28편과 280문항, 오류 없음.
- 빌드 검사: 70페이지, 수식 1,768개, 그림 17개, 내부 파일 링크 118개. 그림의 설명, 크기, 파일과 배포 사본 일치를 확인했다.
- Chromium 320px, 390px, 1280px: 그림 17개 각각의 로딩, 화면 폭, 확대 보기, 확대 및 축소, 닫기와 키보드 초점 복귀 검사 통과.
- 모바일 320px: 70페이지의 가로 넘침, 검색, 주차 이동, QnA 답안 열기, 글자 크기와 테마 전환 검사 통과.
- 어두운 화면에서 SVG 색상 유지. Escape로 확대 보기를 닫으면 본문 링크로 초점이 돌아오고 배경 스크롤이 복구됨.
- 모바일과 데스크톱 스크린샷을 직접 확인했다. 좁은 화면에서 축 글씨가 작아지는 문제는 확대 보기 안의 확대/축소와 스크롤로 보완했다.
- 브라우저 오류 없음. 루트 발표 목록과 기존 발표 URL 유지.

브라우저 검사는 `figure-audit.js`와 `mobile-audit.js`로 다시 실행할 수 있다. 그림의 학술적 타당성은 자동 검사와 별도로 본문의 정의, 예제와 비교해 검토했다.
