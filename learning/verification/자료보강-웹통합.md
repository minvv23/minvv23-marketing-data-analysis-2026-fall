# 자료 보강과 웹 통합 (2026-09-22)

## 자료

- PDF별 심층요약 28개 모두 보강. 이번 변경으로 본문 51,058자 추가.
- 관련 본문에 설명 62개 통합. 기호의 대상·단위, 생략된 수식 전개, 교육용 수치 예, 가정과 적용 한계를 함께 설명.
- QnA는 교수의 개념적 독해 확인 형식을 유지. 16개 QnA의 답안을 보강했으며, 전체 28개 파일에 각 10문항(총 280문항)을 유지.
- 주차별 작성 뒤 주요 전개를 다른 작성자가 교차 검토. IPW/DR 처치 기호와 참 평균함수를 통일하고 광고 잔존계수가 적용되는 단계를 명확히 했다.
- 원본 `literatures`와 `learning/materials`의 98개 주차 파일을 해시로 비교해 일치 확인.

## 검증

원본 구조 검사(28 PDF, 28 요약, 28 QnA, 280문항), 기존 수치 예제 22개 검산, 원본 수식 1,703개 렌더 검사를 통과했다. 웹은 보충문서 수식을 포함한 총 1,768개 수식과 70개 문서를 생성했다. 내부 문서 경로와 로컬 파일 링크를 검사했다.

320px 브라우저 화면에서 전체 문서 이동, 답안 펼치기, 글자 크기, 검색, 읽음 표시를 확인했다. 이전 화면 개편에서 점검한 360·390·430px 기록도 이 폴더에 있다. 실제 휴대폰 검증은 아니다.

## 통합

기존 `presentation/.git`과 `.vercel`을 그대로 `web`으로 이동했다. `web/presentation`은 발표용, `web/learning`은 학습용이며 각각 README가 있다. 원래 공개됐던 날짜별 발표 HTML 주소도 빌드 시 복사해 유지한다. 루트 화면에는 발표 목록만 표시하며 학습 웹은 `/learning/`에 배치한다.

미리보기 배포에서 `/`, `/learning/`, 기존 발표 URL, 학습 PDF 응답을 확인했다. PDF 다운로드는 원본과 해시가 일치했다. 발표 HTML에는 Vercel 미리보기 피드백 스크립트만 자동 추가됐으며 로컬 발표 소스는 이전 커밋과 동일하다.
